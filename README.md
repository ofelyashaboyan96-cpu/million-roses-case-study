# Million Roses · Shopify Case Study

An animated, responsive portfolio page presenting **Million Roses**, a trilingual (Armenian, Russian, English) Shopify flower boutique I designed and built.

**Live case study:** https://ofelyashaboyan96-cpu.github.io/million-roses-case-study/
**Live store:** https://ofelya-shaboyan-szkc1aey.myshopify.com/en-am

## What's inside

| File | Purpose |
|---|---|
| `index.html` | Page structure and all text |
| `styles.css` | Design: store palette, typography, layout, responsive rules |
| `script.js` | Links (edit at the top), scroll-driven bouquet story (SVG drawn in code), reveals, count-up stats, laptop tilt |
| `assets/` | Screen recordings and images of the real store |

## Built with

- Plain HTML, CSS and JavaScript (no frameworks, no build step)
- `IntersectionObserver` for scroll animations and lazy video playback
- CSS-only laptop and phone mockups
- Respects the visitor's "reduce motion" setting
- Hosted free on GitHub Pages

## About the store

- Dawn-based Shopify theme with 15+ custom Liquid sections (collection tabs, same-day delivery banner with countdown, welcome popup, product page rows and FAQ, flower care, testimonials, About, FAQ, Shipping and Contact pages)
- Palette: deep green `#1F3A2B`, cream `#F6F2E9`, sage `#8A9A78`, gold `#B8975A`
- Apps: Translate & Adapt, Shopify Inbox, Judge.me Reviews
